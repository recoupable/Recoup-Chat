# Existing catalog conformance — October 20, 2026

This advances [#2203](https://github.com/recoupable/app/issues/2203) for the three
existing examples. It does not complete the catalog, establish user benefit, or
activate production chat integration. Base: actual main
`ed05ef02d30c828858c3630da55dcaa9b13a9a9f`, which includes #2243 at
`9faf39d56840e008e28bd14ff8197dfb6cec77ab` and #2246's transport tests.

## Observed defects and corrections

1. The panel's child effect focused its reading heading before Radix recorded an
   initial focused element. Native Tab or Shift+Tab at that boundary could reach
   an invisible guard or leave the dialog. The heading now precedes Close, and
   opening focus is set through Radix's `onOpenAutoFocus` callback after its trap
   mounts. The panel no longer issues an early focus request inside the dialog.
   Radix retains trapping, Escape and trigger focus recovery; no custom keyboard
   trap or extra static-content tab stop is introduced.
2. The schema permits a value of `1e12`, whose exact formatted number exceeded the
   distribution's fixed 4.5rem mobile value column. At 320px the value required
   122px in a 72px cell and body scroll width became 350px. The mobile layout now
   pairs label/value above each bar. Wider layouts keep inline columns with an
   intrinsic value width; values remain exact rather than abbreviated.
3. A valid 160-character name with a long unbroken word wrapped in the chart but
   overflowed the calculated sentence. The answer and plain-text alternative now
   allow such words to wrap. The temporary stress fixture was restored afterward;
   the ordinary authored examples and evidence are unchanged.

## Native browser checks

An isolated webpack development preview on port 3220 preserved the original
port-3217 preview. Browser input used the normal Codex In-app Browser, with read-only
DOM measurements; no injected focus, media methods, events, geometry or storage.

- Skip link becomes visibly focused, Enter focuses `#conversation`, and the next
  Tab reaches the response's source control.
- Source open focuses its heading. Immediate Shift+Tab stays on that heading
  inside the dialog; Tab reaches visible Close. Control navigation remains inside,
  Escape restores the source control, and reopening repeats the sequence. The
  reverse-path check was added after independent review caught the earlier
  forward-only repair. Acceptance uses normal native input with fresh observations.
- Standard examples were checked at actual CSS widths 320, 390, 768 and 1440 in
  light and dark. The stress distribution also used those eight width/theme pairs.
  Its 160-character name and exact `1,000,000,000,000` value fit, body scroll width
  equals viewport width, and the value's client/scroll widths both measure 122px.
- The expanded plain-text alternative at 320px has client/scroll widths 280px and
  body scroll width 320px with the same stress data.
- Measured body/muted text contrast is 14.21/5.30 in light and 15.22/7.90 in dark;
  bars against the reading surface are 4.74 and 9.42. These measurements cover
  those actual foreground/background pairs, not every accessibility criterion.

The viewport capability required calibration against actual CSS width. Resizing a
viewport is not evidence of native 200% browser zoom. Access to the Codex native
app surface was denied by computer-use policy; no alternate OS control was used.

## Limits

The full local suite passes 1,403 tests across 342 files after integrating the
actual main above. TypeScript and scoped ESLint pass. The new reading-order
regression failed twice against the original order and passes after the change.
A separate containment regression reproduces escape before any control is visited;
both linked and unlinked source variants pass after the opening-hook repair.

Unit tests protect initial reading/dismiss order, full schema-boundary values and
existing source/replay/media behavior. Browser geometry and focus checks complement
those tests; jsdom does not prove responsive layout or native focus navigation.

Native screen-reader use, real 200% zoom, physical mobile/Safari, audible quality,
all localized/data-poor states, the other representation families, and comparative
user research remain unverified or unimplemented. No full WCAG certification or
completion of the epic is claimed.
